### 🌱 開発の目的・背景

現職で携わったプロジェクトにおいてCakePHPが使用されていたことから、フレームワークへの理解を深めることを目的に制作しました。

Dockerを用いてPHP・CakePHP・MySQLの開発環境を再現し、学習した技術を実際のWebアプリケーション開発に活用しました。

使用している技術のバージョンは現在では古いものですが、業務で使用する技術への理解を深めるため、当時の環境に合わせた構成としています。

<p>&nbsp;</p

なお、当初はアプリケーション本体のサーバー公開を検討していましたが、**2026年10月に報告されたPHPの重大な脆弱性に関するニュースや、使用技術のサポート終了状況を踏まえ、セキュリティ上のリスクを考慮して一般公開を見送りました。**

そのため、アプリケーションを直接操作していただくことはできませんが、代わりにGitHub Pagesで操作動画や機能説明をまとめた紹介サイトを公開しています。

&nbsp;

---

### 🍃 アプリの概要

私は「あつまれ どうぶつの森」のファンなのですが、本編にはない機能として、**住民同士が不要になったアイテムをオークション形式で出品し、自由に売買すること**を思いつきました。

ゲームの世界観を大切にしながら、商品の出品・入札・検索・お気に入り登録など、実際のオークションサイトに近い機能を実装しています。
