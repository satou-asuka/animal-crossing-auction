# AIを活用した紹介サイト制作の記録

記録日：2026-10-23（Asia/Tokyo）

## 対象と区別

| 対象 | 今回の扱い |
| --- | --- |
| 既存CakePHPアプリ | 調査対象。今回の作業ではコード変更なし。過去の開発でのAI使用有無は未確認 |
| docsの紹介サイト | 今回Codexを使用して調査・構成提案・文章作成・HTML/CSS/JavaScript実装・文書化を実施 |

既存アプリ自体を今回AIで開発した、既存不具合を修正した、アプリの実動作を保証した、という記録ではありません。

## AI活用の目的

- Controller・Model・Template・Migrationから、紹介可能な実装と未確認事項を整理する。
- 採用担当者が短時間で機能・画面・構成・工夫を把握できる静的サイトにまとめる。
- 実画面や動画を後から追加できる仕組みと、公開・更新の手順を用意する。
- 根拠のない実績・設計意図や架空の画面を掲載しない。

## 使用したツール

- Codex：ソース調査、提案、実装、記録作成。モデルの詳細名・バージョンはこの記録では確定していない。
- コマンド実行：`rg`、`cat`、`sed`、`find`、`ls`、Python標準ライブラリ等による読み取り・静的確認。
- `apply_patch`：`docs/` 内のファイル作成・編集。
- Git：初回制作ではstatus・diff・remote・branch等の読み取り確認。追加依頼でdocsのcommit・pushが許可された（下記参照）。
- Sitesスキル：静的サイトの設計・ローカル検証に関するガイドを参照。Sitesサービスへの登録・アップロード・公開には使用していない。
- Web検索：追加の質問に対応し、GitHub公式ドキュメントでブラウザーからのファイル追加・編集手順を確認。

ライブラリやフレームワークの追加、ゲーム素材の生成、架空スクリーンショットの生成は行っていません。

### commit・pushの追加依頼

```text
なるほど、じゃあこれをpushすればそのまま見れるって感じね
そうであればそのままpushして
編集は見やすいGithub上でやるわ
```

この追加依頼により、当初のcommit・push禁止から、docsに限ったcommit・pushの許可へ変更された。
既存音声の変更は対象外。GitHub Pagesの公開元設定が必要であることも会話で説明した。
この項目は許可の記録であり、pushや公開が成功した証明ではない。実行結果は会話の報告とGitHubの履歴で確認する。

## AIへの制約と対応

| 制約 | 今回の対応 |
| --- | --- |
| 承認前に変更しない | 初回は調査報告のみ。上記の承認後に実装 |
| 変更をdocs内に限定 | 紹介用ファイルのみ作成。既存音声の作業中変更は保持 |
| 未実装・未確認事項を実績にしない | 静的調査と実動作を区別。自己登録は紹介せず、マイページは掲載保留 |
| 架空の実画面を使わない | 未追加を明記した枠を設置。実物のファイルが読めた場合だけ表示 |
| 個人・秘密情報を掲載しない | 設定・DB・ログ・音声等をコピーしない。コード内の個人メール値も転載しない |
| 初回制作ではcommit・pushしない | 承認なしのcommit・pushは行わず、後の追加依頼でdocsに限って許可された |

### 静的チェック結果

2026-10-23、CodexがPython標準ライブラリとGitの読み取りコマンドで確認した。

- HTMLの開始・終了タグの対応、ID重複なし、h1が1つであることを確認。
