# 操作デモ動画

動画はまだありません。次のファイルを追加してください。

| ファイル名 | 用途 |
| --- | --- |
| `auction-demo.mp4` | 実際のアプリを操作した動画。ブラウザー対応のMP4（H.264等）を推奨 |
| `auction-demo.vtt` | 任意の日本語字幕。WebVTT形式、UTF-8 |

動画のメタデータを読み込めた場合のみプレーヤーを表示します。
動画なし・読み込みエラーの場合は「操作デモは準備中です」を維持します。
自動再生はせず、閲覧者が再生・音量を操作できます。
字幕ファイルがHTTPで見つかった場合のみ、日本語トラックを追加します。

## 撮影案（未実施）

1. ログイン後の商品一覧で検索し、詳細を確認。
2. 画像・最低価格・終了日時を設定して出品。
3. 別のデモアカウントから入札し、入札状態を確認。
4. 終了日時を過ぎた後、終了バッチを実行して結果を確認。
5. 落札後のメッセージ画面で投稿。

1〜2分程度を目安とし、バッチの待ち時間を編集した場合は動画内で明記してください。
Cronの自動実行を確認できていない場合は、手動で実行したバッチを「Cronによる自動実行」と説明しないでください。
メールを撮影する場合も、実際の配送確認後に、デモ用情報だけを掲載してください。
ゲーム音楽をこのサイトへコピーしていません。録画時のBGM・通知・個人情報の映り込みを確認してください。

## 字幕ファイルの書式例

以下は書式例です。実際の動画に合わせて文言と時間を変更してください。

```vtt
WEBVTT

00:00:00.000 --> 00:00:05.000
商品一覧で商品名とカテゴリを指定して検索します。
```

動画・字幕を追加した後は、PC・スマートフォンで再生・シーク・字幕・音量を確認してください。
視覚だけで操作内容が伝わる字幕を付けると、音を出せない閲覧者にも伝わります。
実施した確認は `AI_DEVELOPMENT.md` に追記してください。
