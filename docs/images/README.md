# 実画面キャプチャ

現時点ではアプリの実画面キャプチャはありません。
商品画像・キャラクター画像は、アプリ画面のスクリーンショットとして扱っていません。
このディレクトリに以下のPNGを追加すると、JavaScriptが読み込みに成功した枠から自動表示します。
元画像へのリンクも表示されます。キャプチャ自体は縦横比を維持し、トリミングせず表示します。

| ファイル名 | 撮影する画面・内容 |
| --- | --- |
| `auction-list.png` | 商品一覧。検索・カテゴリ・並び替え・入札件数・お気に入り |
| `item-detail.png` | 商品詳細。商品画像・最低価格・終了日時・入札履歴 |
| `item-create.png` | 出品フォーム。画像選択と終了日時のプリセット |
| `bidding.png` | 自分の入札一覧。最高入札者・上位入札あり等の表示 |
| `favorites.png` | お気に入り一覧 |
| `my-listings.png` | 自分の出品一覧。出品中・落札済み・落札なし終了 |
| `transaction-messages.png` | 落札商品にひもづく投稿と履歴 |
| `mypage.png` | 任意。マイページの動作確認後に撮影し、HTML側にも枠を追加 |

## 撮影・差し替え手順

1. 既存アプリを起動できるローカル環境を用意します。このサイトからアプリやDBへ接続する機能はありません。
2. デモ専用のユーザー・商品を使用して実際に操作します。現状の不整合や実行時エラーは、撮影前に別途確認してください。
3. ユーザー名も含め、公開する情報を確認します。個人のメール・住所・電話番号・パスワード・Cookie・通知・URLの秘密情報を写さないでください。
4. PNGとして上記の名前で保存します。幅1440px程度を目安に、文字が読める状態で圧縮してください。固定サイズである必要はありません。
5. HTTPプレビューで実画面が表示され、元画像へのリンクが開くことを確認します。異なる画面を使う場合は `index.html` の説明とaltも更新してください。
6. 撮影・掲載確認を実施した人、日付、確認内容を `AI_DEVELOPMENT.md` に追記します。

キャプチャに含まれるゲーム由来の画像は自作の素材として紹介しません。サイト本文も非公式の個人制作作品紹介と明記しています。
画像が未追加の枠は「実画面の画像を準備中」と表示されます。実物の代わりに架空のスクリーンショットを作らないでください。
